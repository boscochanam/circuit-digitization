# Phase 1 — independent assessment, before the structured validation notes

Assessment recorded 2026-09-07 against detached HEAD `36b9a8e`, after reading the ordered context pack, original manuscript, author diffs, current changes, and load-bearing implementation. No production edits.

Pranavesh's strongest contribution is experimental infrastructure for wire extraction. PR #2 introduced the configurable harness, PCA endpoints, overlap deduplication, component anchoring, recovery experiments, a console entry point, and a regression test. PR #4 broadened that infrastructure into threshold/skeleton/Hough/hybrid experiments, class-aware ports and stroke repair, quality analysis, a learned branch, and a MethodsX draft. These are real implementation contributions. Their historical benchmark scores cannot simply be substituted for the later corrected 134-image evaluation, and the learned branch fine-tunes and evaluates on the same GT file list. Neither PR establishes the later endpoint-graph/completion research or authorship of the August revision.

Closed PR status is not a reliable content-survival test. PR #77's author commit `22d6882` is an ancestor of the present checkout through Bosco's conflict-resolution merge `0a286d4` and replacement PR #78 (`aab509e`). Its layout and prose changes largely survive, though later front-matter and figure handling supersede parts. This was not merely formatting: it rewrote the abstract and completion exposition, changed a funding placeholder to a factual no-funding declaration, expanded Pranavesh's name, added contact details, and supplied his biography. PR #75 proposed a different legacy-paper presentation and generator; its author ownership and overlap with Bosco-authored history must be qualified because the exported pull-file evidence has blank filenames and does not supply a unique author commit.

The current revision is useful research evidence, not a submission-ready package. It openly reports a low detected-box result and a crossover false merge, and adds an informative zero-effect module-ablation table. Yet its title still promises SPICE netlists, conclusion lacks an explicit values limitation, and its abstract/introduction still generalize a GT-box wire-ceiling result into end-to-end joining dominance. It continues to promise structural validity despite a base graph that unconditionally unions proximity edges and a completion guard that cannot undo existing shorts. A further concrete numerical error is the claim that scale-relative tolerances are worth +0.005 when the table improves from 0.816 to 0.820 upon removing them.

I disagree with Claude's plan where it treats “statistically indistinguishable” as a license to claim matched accuracy: a nonsignificant paired difference is not an equivalence test. I also reject its global structural-guarantee language and its automatic Otsu 0.789→0.828 correction; the later committed rerun note supports 0.789, which needs source-pinned reproduction rather than deference to either prose source. Causal crossover analysis is more informative than blaming C66 from exposure alone; the stored report specifically clears C66's suspected crossing edges and identifies C242 instead. Conversely, the plan is right to require explicit scope, real module ablations, statistical support, annotation-process honesty, and author confirmation for submission metadata.

The strongest defensible claim is a controlled component-pair connectivity result on a small, human-verified subset using supplied component labels. It does not certify exact terminal assignments, complete netlists, simulation correctness, unseen-drafter generalization, or end-to-end detector performance. Phase 2 will separate verified facts, implementation deductions, historical evidence, and unresolved claims, and record fresh tests and artifact recomputation.
